DeepSeek Harness portable quick guide
=====================================

1. start-desktop.cmd
   Launches the bundled Electron desktop shell.
2. start-web.cmd
   Uses Node.js from PATH to launch the web entry in a browser.
3. update.ps1 or dsh update
   Downloads a complete release, verifies SHA-256, and atomically replaces runtime.
4. setup-shortcuts.ps1
   Creates a desktop shortcut and adds this portable root to the user PATH.

This release is not signed by a trusted commercial CA. Self-signed certificates do
not bypass Smart App Control or SmartScreen, so no certificate or trust store is
created automatically. Verify SHA256SUMS.txt before running downloaded files.

All application files are under runtime/. Do not delete or rename that directory.
