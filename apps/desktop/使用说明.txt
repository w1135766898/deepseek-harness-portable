DeepSeek Harness for Win v1.3.0
================================

英文说明：使用说明.en.txt

1. start-desktop.cmd
   启动内置 Electron 桌面端。

2. start-web.cmd
   使用 Electron 内置的 Node.js 在浏览器中启动 Web 界面，无需系统 Node.js。

3. dsh.cmd 或 update.ps1
   检查最新分发版本，下载完整发布包，校验 SHA-256，验证发布清单，
   并以整体替换方式更新 runtime。桌面端会在更新包准备好并确认重启前保持运行。

4. 更新日志
   打开托盘菜单即可查看当前版本、历史发布记录和组件版本。桌面外壳会
   使用 GitHub 镜像，并在网络不可用时回退到本地发布清单。更新通知是标题栏
   下方居中的短横幅，7 秒或关闭后销毁；可选择“不再提示”避免同版本重复打扰。
   如果在线检查失败，更新中心会显示错误状态和重试入口，不再阻塞主界面。

5. 原生 Logo 菜单
   侧边栏展开时，点击蓝色原生 Logo 打开桌面菜单；收起时左键仍展开侧边栏，
   右键 Logo 打开桌面菜单。

6. setup-shortcuts.ps1
   创建桌面快捷方式，并将当前便携目录加入用户 PATH。

7. uninstall.cmd 或 uninstall.ps1
   删除便携应用、快捷方式和 PATH 项。除非明确确认，否则会保留用户数据。

插件市场会在每个 Web profile 中预装一次，可在“设置 → 插件 → 已安装”中
关闭或卸载；之后重启不会自动恢复。市场插件来自第三方，安装前请审查来源和权限。

本版本没有可信商业 CA 签名，SmartScreen 或 Smart App Control 可能警告或
阻止运行。程序不会自动创建证书或修改信任存储。运行下载文件前请先核对
SHA256SUMS.txt。

所有应用文件都位于 runtime/ 下，请不要删除或重命名该目录。
