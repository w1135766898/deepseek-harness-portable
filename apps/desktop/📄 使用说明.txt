================================================================
           DeepSeek Harness 便携版使用指南
================================================================

【快捷启动】
1. 🚀 启动 DeepSeek Harness (推荐网页版).bat
   - 推荐使用！100% 免疫 Windows 11 智能应用控制 (SAC) 拦截。
   - 自动在默认浏览器中打开 http://127.0.0.1:3080。

2. 🖥️ 启动桌面独立窗口.bat
   - 启动原生 Electron 独立窗口与系统托盘。

3. 🔄 检查与更新.bat
   - 一键检查 GitHub 最新发布，自动增量更新程序，保留所有数据。

4. ⚙️ 创建桌面图标与解除拦截.bat
   - 自动在电脑桌面创建快捷方式，并为可执行文件添加本机信任签名。

【命令行支持】
在终端中执行 dsh 命令即可启动：
- dsh             : 启动网页版服务
- dsh desktop     : 启动桌面独立窗口
- dsh update      : 执行在线热更新
- dsh trust       : 一键创建快捷方式并添加本机信任

【注意】
- 本软件所有底层运行文件均存放在 runtime/ 目录下，请勿随意删除 runtime/ 中的文件。
- 项目主页: https://github.com/w1135766898/deepseek-harness-portable
