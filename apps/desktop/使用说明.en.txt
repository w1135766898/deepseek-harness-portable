DeepSeek Harness for Win v1.0.3
================================

Chinese guide: 使用说明.txt

1. start-desktop.cmd
   Launches the bundled Electron desktop shell.

2. start-web.cmd
   Uses Node.js from PATH to launch the Web surface in a browser.

3. dsh.cmd or update.ps1
   Checks the latest distribution, downloads a complete release, verifies SHA-256,
   validates the release manifest, and replaces runtime as one operation.

4. Release Notes
   Open the tray menu to read the current release, release history, and component
   versions. The desktop shell uses the GitHub mirror and a bundled local fallback.

5. setup-shortcuts.ps1
   Creates a desktop shortcut and adds this portable root to the user PATH.

6. uninstall.cmd or uninstall.ps1
   Removes the portable application, shortcuts, and PATH entry. User data is kept
   unless you explicitly confirm its removal.

This release is not signed by a trusted commercial CA. SmartScreen or Smart App
Control may warn or block it. No certificate or trust-store change is performed
automatically. Verify SHA256SUMS.txt before running downloaded files.

All application files are under runtime/. Do not delete or rename that directory.
